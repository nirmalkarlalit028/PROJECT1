    • Basic / Structure Tag

    1. DOCTYPE HTML - This declaration tells the browser that the document is an HTML5 file.
    2. HTML - The "root" element that wraps all other content on the entire page.
    3. HEAD - A container for metadata (information about the page) that doesn't appear to viewers, such as the title and links to CSS.
    4. TITLE - Located inside the head, this sets the name of the page shown on the browser tab.
    5. BODY - This contains all the visible content, including text, images, buttons, and links.
